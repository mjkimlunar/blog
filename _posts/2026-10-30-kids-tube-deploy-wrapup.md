AI 서비스 인 프로덕션(모두의연구소) 모듈 "프로덕트 설계부터 서비스 배포 전략까지"를 정리했습니다. 강의는 AI 친구 에이전트로 배포를 가르쳤고, 저는 매일 그 개념을 가족용 앱 **키즈 튜브**(부모가 승인한 YouTube 영상만 아이에게)에 옮겼습니다.

**👉 글 보기: [라즈베리파이에서 블루그린까지](/blog/kids-tube-wrapup/)** (그림 위주, 날짜를 누르면 배포 구조가 바뀌는 페이지)

![10/29 블루그린 배포 구조](/blog/kids-tube-wrapup/diagram-10-29.png)

- 10/19 PRD 한 장 → 10/20 Cloud Run 첫 배포 → 10/22 GitHub Actions 자동 배포(WIF) → 10/26 CI 두 시간대·staging·Dockerfile → 10/27 이미지 승격 → 10/28 무중단 개념 → 10/29 Cloud Run 블루그린 + 롤백 버튼
- 열흘 결과: 배포 중 요청 실패 0 / 2,868, rollback 버튼 31초, PR 81개 · main 직접 푸시 0, 자동 시험 42개 × 두 시간대
- 오래 남을 실패 셋: 새벽 내역이 전날로(UTC), 사진 글자 읽기가 staging에서만 503(tesseract), 스모크 테스트가 옛 버전을 봄(301)
- 아직 못 한 것: 답의 품질(Langfuse), 망가진 버전 시험, 데이터 구조를 바꾸는 배포
